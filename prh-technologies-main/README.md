# PRH Technologies

Production-ready local application package for PRH Technologies.

## Run on Windows

1. Open Command Prompt in this folder.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000
5. Admin login: http://localhost:3000/#/admin-login

Initial local admin:
- Email: owner@prhtechnologies.com
- Password: ChangeMe@123

## Important

This package is intentionally clean at the root: `package.json` is in the same folder as `server.js`.
Do not upload `prh.sqlite` or `node_modules` to GitHub.
Change the initial admin password before production deployment.
